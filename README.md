# Talk Time with Dad

A small web app with five conversation questions per topic for speech practice.

- Live: `index.html` (questions refreshed by a scheduled update; edit only the JSON in `<script id="questions">`)
- Test: `test/index.html` (3-day daily test; its `bank` keeps every test question for reuse)
- Usage counter: GoatCounter, set `GOATCOUNTER` in both pages.
